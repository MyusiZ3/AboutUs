# Tentang Kita (AboutUs)

**Tentang Kita** (AboutUs) is a web-based conversation card game designed to spark meaningful deep talks and genuine connections between couples, close friends, and families.

---

## Features

- **5 Card Editions**: Couples, Close Friends, Marriage, Self-Reflection, and Family (plus a combined deck option).
- **Customizable Players**: Support for 2–6 players with custom names and automated turn tracking.
- **Question Depth**: Filter questions by lighter icebreakers or deeper reflection.
- **Multilingual Support**: Available in Indonesian, English, and Japanese.
- **Bookmark System**: Save memorable questions during play and review them in the end-of-session summary.
- **Clean UI & Audio**: Smooth animations, celebratory effects, and background ambient audio.

---

## Tech Stack

- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Styling**: Vanilla CSS
- **Deployment**: GitHub Pages (`gh-pages`)

---

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Local Setup

```bash
# Clone the repository
git clone https://github.com/MyusiZ3/AboutUs.git
cd AboutUs

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build & Deploy

```bash
# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
